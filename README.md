# prosthetic-arm

## Overview

This project focuses on the design and development of an electric prosthetic arm that can assist in performing basic hand and arm movements using electronically controlled actuators.

The system combines mechanical components, electronic control, and motor actuation to create a functional prosthetic-arm prototype.

## Objectives

* Design a low-cost prosthetic arm prototype
* Control the movement of the arm using electronic signals
* Implement motor-based movement
* Integrate mechanical and electronic components
* Test the movement and overall operation of the prototype

## System Components

* Microcontroller
* Motors/Actuators
* Motor driver
* Sensors/Input system
* Power supply
* Mechanical arm structure
* Connecting wires and electronic components

## Working Principle

The user input is received by the control system. The microcontroller processes the input and generates control signals for the motors.

The motors then produce the required movement of the prosthetic arm.
